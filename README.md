# About-Me · José Pablo

Presentación personal adaptable a móviles y computadoras, basada en el PDF de 2025 y actualizada en octubre de 2026.

## Contenido
- Foto principal proporcionada por José Pablo.
- Encuesta interactiva con **10 respuestas iniciales por pregunta**. Las proporciones se estimaron a partir de las gráficas del PDF, que tenían etiquetas discordantes. El voto del visitante se guarda solo en su navegador con localStorage y modifica los gráficos localmente; **no se sincroniza entre usuarios**.
- Carrusel con seis comentarios originales y expansión del comentario largo.
- Dos líneas del tiempo con hitos escalonados.
- Portadas originales de sus gustos; actualmente incluye Yakuza 3 Remastered.
- Playlist de Spotify embebida. Se omite el parámetro pt del enlace compartido para no publicar el token de invitación.
- Meme original y dos opciones finales que abren WhatsApp.
