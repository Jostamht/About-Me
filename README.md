# About-Me — José Pablo

Una adaptación web interactiva de una presentación personal creada originalmente en 2025.

## Contenido
- Portada con retrato extraído del PDF original.
- Gráficas recreadas a partir de la encuesta.
- Testimonios, cronologías, aficiones y preguntas frecuentes.
- Diseño adaptable a móvil y escritorio.
- Botones finales de demostración (sin recopilación de datos).

## Uso
Abre `index.html` en el navegador. No requiere servidor ni paso de compilación.

## Archivos
- `index.html`: contenido.
- `styles.css`: diseño.
- `script.js`: interacciones.
- `assets/jose-pablo.webp`: retrato optimizado.

Los títulos de obras y la selección de aficiones reflejan la presentación de 2025 y no pretenden representar una actualización a 2026.
